# Python Learning Repository

This repository is a personal documentation and project archive for my learning journey through the course "100 Days of Code - The Complete Python Pro Bootcamp" by Angela Yu.

It contains exercises, mini-projects, and notes organized by the sections of the course, reflecting my progress as I learn Python from the fundamentals to more advanced topics. Each folder serves as a record of the concepts I practiced and the projects I built along the way.

## Purpose

- Track my Python learning progress
- Save code examples and projects completed during the course
- Build a personal reference for concepts learned throughout the bootcamp

## Course Information

- Course: [100 Days of Code - The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code)
- Instructor: Angela Yu
